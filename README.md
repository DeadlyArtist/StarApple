# Star Apple
Minecraft mod that adds the Star Apple and its enchanted variant.

To craft it surround an apple with nether stars. The enchanted variant is uncraftable, unless either [Nether Star Block](https://github.com/DeadlyArtist/NetherStarBlock) or [All The Tweaks](https://www.curseforge.com/minecraft/mc-mods/all-the-tweaks) are installed. If they are, surround an apple with nether star blocks to craft it.
